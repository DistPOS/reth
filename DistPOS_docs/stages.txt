Estimation method and assumptions
    • What “Specialist roles” means here: total GPT‑5 context usage across the full lifecycle (architecture, coding assistance, code review, debugging triage, technical writing), not compute or engineer-hours.
    • Repo baseline: Reth is a large, modular Rust client; integration is additive via new crates, Execution Extensions (ExEx), and RPC extensions per DistPOS_docs/DistPOS_TRD.txt. No monolithic fork planned.
    • Specialist role drivers:
        ◦ Breadth of changes across consensus, txpool, P2P subprotocols, RPC, ExEx, and Solidity contracts.
        ◦ Iterative debugging and multi-node testnets.
        ◦ Dual-network e2e tests for interchain and Merkle proof paths.
        ◦ Documentation and operator-facing guides.
    • Role mapping across all stages:
        ◦ Architect = design docs, API/trait contracts, integration and test strategy.
        ◦ Coder = Rust crates, Solidity contracts, glue, configs.
        ◦ Reviewer = structured code reviews and design reviews.
        ◦ Debugger = failure triage, instrumentation, test failure analysis.
        ◦ Tech Writer = operator/dev docs, RPC references, runbooks.
